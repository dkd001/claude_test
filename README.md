# 坦克大战 · Battle City

经典 FC 红白机《坦克大战》（Battle City）的 HTML5 复刻版。纯原生 HTML + Canvas + JavaScript 实现，游戏本体为**单文件** `index.html`，零依赖、打开即玩。

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Platform](https://img.shields.io/badge/platform-Web-brightgreen.svg)

## 🎮 玩法

你驾驶一辆黄色坦克，目标有两个：

1. **消灭本关所有敌方坦克** —— 全部消灭即过关，进入下一关；
2. **保卫基地 🦅** —— 基地有 **10 点生命**，被击毁（无论是敌人还是你自己的流弹）则游戏结束。

敌人 AI 分两类：一类**追击玩家**，一类**主攻基地**，会主动开路、射击玩家和基地，越往后越难。

## 🕹 操作

| 动作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | `W A S D` 或 `↑ ← ↓ →` | 虚拟方向键 |
| 射击 | `空格` / `J` | 红色按钮 |
| 暂停 | `P` | — |
| 开始 / 重新开始 | `Enter` | 点击按钮 |

## 📖 图鉴

### 敌方坦克

| 图标 | 名称 | 生命 | 速度 | 得分 | 射击间隔 | 行为 |
|---|---|---|---|---|---|---|
| 🔴 | 普通坦克 Basic | 1 | 55 px/s | 100 | 1.9s | 主攻基地 |
| 🔵 | 快速坦克 Fast | 1 | 115 px/s | 200 | 1.5s | 追击玩家 |
| 🟠 | 强力坦克 Power | 1 | 72 px/s | 300 | 1.1s | 追击玩家 |
| 🟢 | 装甲坦克 Armor | 3 | 46 px/s | 400 | 2.1s | 主攻基地 |

### 地形

| 图标 | 名称 | 说明 |
|---|---|---|
| 🧱 | 砖墙 | 可被任意子弹摧毁，是主要掩体 |
| ⚙️ | 钢板 | 普通子弹无法击穿，仅 2 星以上火力可摧毁 |
| 🌊 | 河流 | 坦克无法通过，子弹可穿过 |
| 🌳 | 草丛 | 坦克可穿过，且会被隐藏 |
| 🦅 | 基地 | 10 点生命，被毁则游戏结束 |

### 道具

敌方坦克被击毁时约有 25% 概率掉落道具，驾驶坦克压过即可拾取。

| 图标 | 名称 | 效果 |
|---|---|---|
| ⭐ | 火力强化 | 火力 +1（最多 3 级）：射速提升、同屏子弹更多；2 星起可击穿钢板 |
| 🛡 | 护盾 | 8 秒无敌 |
| ❤ | 额外生命 | 生命 +1（最多 9 条） |
| 💣 | 全屏炸弹 | 立即消灭场上所有敌人 |

### 玩家参数

| 项目 | 数值 |
|---|---|
| 移动速度 | 130 px/s |
| 生命 | 3 条（拾取 ❤ 最多 9 条） |
| 子弹速度 | 340 px/s（敌方 260 px/s） |
| 射击间隔 | 0.26s 起（随 ⭐ 降低，最低 0.12s） |
| 同屏子弹 | 2~4 发 |
| 复活 | 死亡后 1 秒原地重生，附带 2 秒无敌 |

### 关卡规则

| 项目 | 规则 |
|---|---|
| 每关敌人数量 | min(4 + 关卡×2, 18)：第 1 关 6 个，封顶 18 个 |
| 同屏敌人上限 | min(3 + ⌊关卡/3⌋, 5) |
| 敌人出生 | 顶部 3 个出生点，间隔约 1.2~2.0 秒 |
| 地图 | 2 张地图循环使用 |
| 过关 | 消灭全部敌人后停顿 2 秒，自动进入下一关 |

## ✨ 特性

- 经典地形：砖墙、钢板、河流、草丛、基地
- 4 种敌方坦克，AI 分「追击玩家」与「主攻基地」，会主动开路、攻击
- 道具系统：⭐ 火力强化 / 🛡 护盾 / ❤ 额外生命 / 💣 全屏炸弹
- 关卡递进、得分与本地最高分、爆炸粒子、屏幕震动、复古音效
- 支持键盘与移动端触屏

## 🚀 运行

直接双击 `index.html`，或部署到任意静态托管（如 GitHub Pages）。
